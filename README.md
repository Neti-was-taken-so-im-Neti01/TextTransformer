## Opis Projektu

TextTransformer to program napisany w języku Java, który służy do modyfikowania stylu i struktury wprowadzonego tekstu, umożliwiając na odwracanie, kapitalizowanie bądź pomniejszanie tekstu a także na rozwijanie i zwijanie skrótów, jak i zamianę liczb na ich słowny odpowiednik. Program ten wykorzystywać będzie REST API do komunikacji i integracji z innymi narzędziami, będzie miała swoje własne GUI do lokalnego wykorzystania, a swoje działanie opierać będzie o wzorzec projektowy Dekorator wykorzystany do modyfikacji tekstu.
